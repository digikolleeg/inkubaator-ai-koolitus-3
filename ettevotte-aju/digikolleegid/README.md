# Digikolleegid

Iga digikolleeg teeb ühte tööd. Salvesta tema juhis faili `digikolleeg.md` eraldi alamkaustas, näiteks `vastaja/digikolleeg.md`.

Juhise koostad töötoas intervjuu abil ([`intervjuu/digikolleeg-intervjuu.md`](../../intervjuu/digikolleeg-intervjuu.md)). Seda pole vaja enne valmis kirjutada. Juhises on töö kirjeldus, piirid ja failinimed, mida uus vestlus peab lugema. Hinnad ja tingimused jäävad ühte kohta, faili `teadmus/faktid.md`.

Kui digikolleeg on valmis, lisa ta faili `kaart.md` tabelisse.
