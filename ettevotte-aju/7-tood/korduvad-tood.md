# Korduvad tööd

Pane kirja 3–5 tööd, mida teed iga nädal peaaegu samamoodi. Hinda ajakulu oma töö järgi, umbkaudsest arvust piisab.

Tundi kuus = kordi nädalas × minutit korraga × 4,3 ÷ 60.

| Töö | Mis selle käivitab | Kordi nädalas | Minutit korraga | Tundi kuus | Kust vajalik info tuleb | Kas viga on kohe näha | Halvim, mis vea korral juhtub | Aste praegu |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

Aste: 0 = teen täiesti ise · 1 = digikolleeg teeb mustandi, mina käivitan · 2 = loeb sisendi ise ühendatud allikast · 3 = käivitub ise.
