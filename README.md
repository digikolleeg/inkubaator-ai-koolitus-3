# Digikolleegi töötuba

Tallinna Ettevõtlusinkubaator, 24. november 2026, kell 13–17.

## Alusta siit

1. **Enne töötuba:** [tee eeltöö](EELTOO.md). Arvesta 30 minutiga.
2. **Töötoa ajal:** töötoa materjal lisandub siia enne 24. novembrit.

Giti pole vaja. Vajuta GitHubis **Code → Download ZIP** ja paki lahti.

## Mida töötoas ehitame

Ehitame sulle digikolleegi, kes koostab vastuse mustandi üht tüüpi kliendikirjadele. Ta kasutab sinu ettevõtte fakte ja kirjutab sinu häälega. Saatmise otsustad sina.

```text
pöördumine -> digikolleeg loeb sinu faile -> mustand või küsimus sulle
                                              |
                          vale vastus -> parandus õigesse faili -> uus vestlus
```

Kell 17 oskad ilma juhendajata:

- avada uue vestluse ja anda digikolleegile õiged failid;
- anda talle kirja, mida ta pole varem näinud;
- saada vastuse mustandi või küsimuse, kui vastamiseks on infot puudu;
- märgata väljamõeldud fakti või lubadust ja parandada juhist õiges failis.
